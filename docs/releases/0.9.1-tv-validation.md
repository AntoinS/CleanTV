# CleanTV 0.9.1 / Spotify 1.0.1 — TV validation

Date: 2026-11-11. The release APK (Android build 29) was installed in place over CleanTV 0.9.0 on the Philips Android TV. Spotify 1.0.1 was already installed and enabled, and its exact package metadata matched the published package.

Eleven native 1920×1080 screenshots covered the compact/expanded player in Dock and List, dark/light/cover tint, and transparency at 0%, 60%, 95% and 100%. The prepared Frost images decoded and remained aligned with the actual wallpaper. No clipping or new focus border was observed. The owner confirmed that the player looks correct and audio stays on the previous Spotify device.

After temporary visual tests, all saved appearance preferences and design values matched the baseline exactly. Spotify credentials and remote add-on data were unchanged. Effective Home, disabled Google launcher, input-method selection, media access and accessibility settings matched the baseline. Previous APK and private app-data backups are retained locally; no private screenshots or device/account identifiers are published.

This is native visual acceptance of the UI patch. Installation used ADB. The full reboot and Android installation-cancellation matrices were not repeated in this check. The existing local and GitHub suites, Android lint/unit/build checks, and browser/editor checks at 720p, 1080p and 4K passed before deployment.

The same immutable APK is promoted from prerelease to the regular 0.9.1 release. Its tag, APK and original release assets are unchanged. `updates/stable.json` and the added `stable-update.json` asset describe the approved update. Earlier prerelease metadata remains an historical snapshot.
